# Security Policy

## Reporting a Vulnerability

We take the security of `nti-benchmark` and the NTI ecosystem seriously. If you discover a vulnerability, please report it responsibly rather than opening a public issue.

### Security Contact

Please report security issues via email to:
- **Email:** security@nti-standard.org (or abisheakp197@gmail.com)

### What to Include

When reporting a vulnerability, please include:
- A description of the vulnerability and its potential impact.
- Clear steps or a proof-of-concept (PoC) script to reproduce the issue.
- Details of any affected versions.

### Response Policy

- **Acknowledgement:** We will acknowledge receipt of your report within 24 hours.
- **Assessment:** We will assess the issue and provide an estimated timeline for remediation.
- **Disclosure:** We ask that you give us reasonable time to release a patch before publicly disclosing the issue.
